# BieTech Tech Portfolio

Portfolio website responsive dengan tema dark futuristic / tech.

## File
- index.html
- style.css
- script.js

## Cara menggunakan
1. Extract ZIP.
2. Buka `index.html` di browser.
3. Ganti data personal, link sosial media, project, email, dan nomor WhatsApp.
4. Untuk CV, upload file PDF lalu ubah link `Download CV` di `index.html`.

## Bagian yang perlu diganti
- Nama/profesi
- Deskripsi About
- Statistik
- Project
- Experience
- GitHub / LinkedIn / Instagram
- Email
- WhatsApp
- Lokasi

## WhatsApp
Cari `6281234567890` di `index.html` dan `script.js`, lalu ganti dengan nomor WhatsApp Anda dalam format internasional tanpa tanda +.
